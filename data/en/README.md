# Английский: словарь и проверка источников

Компактный словарь собран в `app/src/main/assets/en/`. Чтение словаря — `en/EnDictionary.kt`,
разбор сокращений и притяжательных форм — `en/EnForms.kt`.
С версии 0.25.0 `en/EnEngine.kt` подключает словарь к читалке и выбору языка (`en-US`).
Данные китайского и испанского языков не меняются.

## Сборка словаря

```sh
python3 -m unittest discover -s tools -p 'test_*en_dict*.py' -v
python3 tools/build_en_dict.py --sources .work/en-dictionary/sources --out app/src/main/assets/en
```

Сборщик использует оба Викисловаря и частотный список. Сохраняет статьи с русскими значениями /
переводами, частотные слова и статьи с частотными формами. Полный английский Викисловарь в APK
не переносится. Цитаты, примеры, этимологии и аудио не копируются. Машинных переводов нет.

- `dict.tsv`: ключ в нижнем регистре → JSON-массив статей по частям речи.
  `w` — написание, `p` — часть речи, `r` — русские значения русского Викисловаря,
  `e` — английские определения, `t` — русские переводы с английской подписью значения (`g`, `r`),
  `i` — IPA и пометы (`v`, `t`), `f` — частотный ранг, `c` — требование точного регистра.
- `forms.tsv`: форма → JSON-массив связей (`l` — исходный ключ, `p` — часть речи,
  `t` — грамматические пометы, `c` — точное написание для зависимых от регистра связей).
- `ranks.tsv`: ключ → частотный ранг 1–16 000, без статей с требованием точного регистра.
  Загружается в фоне для уровней и рекомендаций; обход JSON всего словаря не нужен.
- `manifest.json`: формат 2, число записей, размеры и SHA-256 источников и всех трёх таблиц.
- `NOTICE.txt`: лицензии и авторство; доступен из «О приложении».

TSV отсортированы по байтам UTF-8. Загрузчик использует существующий `SortedTsv`: файлы один раз
копируются из APK и отображаются в память вместе с индексом строк. Расшифрованные статьи
хранятся в ограниченном кеше. При обновлении приложения кеш файлов заменяется.

У каждой части речи до шести русских и английских определений, до восьми групп переводов
и восьми вариантов произношения. Ранг — минимальная позиция слова или его словарной формы
в исходном частотном списке; это приблизительная частотность, не CEFR.

`EnDictionary.lookup()` возвращает словарные разборы, варианты раскрытия сокращения и разбор
основы притяжательной формы отдельно. `I'd` не подменяется одним `I`. Для `John's` сохраняется
неоднозначность; для множественного притяжательного слова единственные `is/has` отбрасываются,
когда все словарные разборы основы указывают на множественное число.

Результат сборки и ограничения: [ENGLISH_DICTIONARY_BUILD.md](../../docs/ENGLISH_DICTIONARY_BUILD.md).
Подключение к приложению: [ENGLISH_READER_0.25.0.md](../../docs/ENGLISH_READER_0.25.0.md).

## Аудит источников

- `audit/coverage.json` — покрытие частотного списка и двух книг.
- `audit/sources.json` — адреса, даты выгрузок, размеры и SHA-256 входных файлов.
- `audit/probes.json` — словарные разборы выбранных диагностических слов; без цитат и примеров источников.
- `audit/gaps_top5000.tsv` — пробелы среди первых 5 000 позиций частотного списка;
  это список для проверки, не готовая очередь машинного перевода.
- `audit/book_gaps.tsv` — по 50 самых частых непокрытых слов в каждой книге.
- Итоги и ограничения: `docs/ENGLISH_DICTIONARY_AUDIT.md`.

## Повторение

Входные файлы хранятся в игнорируемой `.work/en-dictionary/sources/`, большие выгрузки в Git не добавлять.
Адреса указаны в `audit/sources.json`. Для страниц с датами также нужны:

- `english-index.html` — https://kaikki.org/dictionary/English/
- `ru-english-index.html` — https://kaikki.org/ruwiktionary/Английский/

Перед повтором сравнить SHA-256 с манифестом: по тем же адресам публикуются новые версии.
JSONL можно передавать как обычный файл или gzip — формат определяется по содержимому.

```sh
python3 -m unittest discover -s tools -p test_audit_en_dictionary.py -v
python3 tools/audit_en_dictionary.py --sources .work/en-dictionary/sources --out data/en/audit
```

Kaikki помечает поязычные postprocessed-выгрузки устаревающим интерфейсом. При их удалении
нужно перейти на raw-выгрузки с https://kaikki.org/dictionary/rawdata.html и фильтровать `lang_code=en`.
Текущий аудит привязан к конкретным снимкам из манифеста.

## Что считается покрытием

Прямое русское значение — содержательная статья русского Викисловаря, а не описание формы.
Покрытие с формами добавляет только связи из словарных данных. Варианты написания разрешаются,
когда у слова нет собственного значения. Формы с устаревшими или ошибочными пометами исключены.
Аббревиатуры и сокращения нескольких слов не считаются грамматической формой одного слова.
Полностью прописные статьи исключены, кроме местоимения `I`, чтобы `GO` не смешивалось с `go`.

Объединённое русское покрытие дополнительно использует переводы из английского Викисловаря.
Они сохраняют английскую подпись значения, но ещё не сопоставлены с каждым русским значением.
Имена не исключаются из общего покрытия. Источниковая метка имени в списке пробелов — только сигнал для проверки.

Покрытие — наличие хотя бы одного подходящего словарного разбора. Это верхняя оценка доступности данных,
не оценка точности перевода, выбора части речи или готового английского движка.
Разделённые фразовые глаголы этим аудитом не проверяются.

Частотность — субтитры, а не учебные уровни CEFR. Неполные токены, сокращения с точкой,
числа и другие строки вне выбранного формата слов исключены из знаменателя и перечислены в агрегатах.
Ранги при этом остаются исходными. В книгах удалены заголовок и лицензия Gutenberg;
разбивка на слова механическая, без ручной разметки имён, сокращений и притяжательных форм.
