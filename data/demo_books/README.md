# Пробные книги Amauta Reader

Три оригинальных коротких рассказа для знакомства с читалкой: испанский,
английский и китайский. Это не фрагменты пользовательских вложений или чужих изданий.
Тексты подготовлены для проекта и предоставляются по CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

Исходники — JSON в этой папке. `python3 tools/build_demo_books.py` создаёт небольшие
детерминированные EPUB 2 в `app/src/main/assets/demo/`. Файлы работают офлайн и
не требуют DeepSeek. В каждом рассказе три главы; переводов предложений в тексте нет —
используются обычные словарные подсказки приложения.

`v1` в имени — стабильная редакция: после добавления сохраняются обычный ID книги,
прогресс и исправления. При изменении самого текста для новой редакции следует
выбрать новое имя, чтобы не сдвигать привязки у уже читающих пользователей.
