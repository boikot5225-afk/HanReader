# Языковая «розетка» (экспериментальная ветка)

Эта ветка — эксперимент с другими языками. Основная ветка и бета её не видят:
сборка здесь публикует только артефакт в Actions, не бету, а приложение ставится
отдельно (`com.hanreader.app.es`, «HanReader ES»), не трогая книги и слова в основном HanReader.

## Что сделано (шаг 1)

`lang/LanguageModule.kt` — общий интерфейс языка:

| Часть | Где |
|---|---|
| описание языка: тег для карточек и озвучки, название, «строка над словом», уровни, конец предложения | `LanguageInfo`, `Languages` |
| разбивка абзаца на слова + строка над словом | `LanguageModule.chapter()` → `PreparedText` |
| короткий перевод над словом, перевод для карточки | `glossShort()`, `cardTranslation()` |

Китайский (`ZhEngine`) — первый модуль. `ChapterBuilder`, озвучка и язык карточек идут через розетку.
Внешне приложение не меняется.
