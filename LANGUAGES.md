# Языковая «розетка» (экспериментальная ветка)

Эта ветка — эксперимент с другими языками. Основная ветка и бета её не видят:
сборка здесь публикует только артефакт в Actions, не бету, а приложение ставится
отдельно (`com.hanreader.app.es`, «HanReader ES»), не трогая книги и слова в основном HanReader.

## Что сделано (шаг 1)

`lang/LanguageModule.kt` — общий интерфейс языка. Обязательное — только основа,
остальное имеет нейтральные значения по умолчанию:

| Часть | Где | Обязательно |
|---|---|---|
| описание языка: тег для карточек и озвучки, название, «строка над словом», уровни, конец предложения, буквы языка | `LanguageInfo`, `Languages` | да |
| разбивка абзаца на слова + строка над словом | `chapter()` → `PreparedText` | да |
| короткий перевод над словом, перевод для карточки | `glossShort()`, `cardTranslation()` | да |
| чтение для карточки (пиньинь) | `reading()` | нет |
| что стоит учить, имена | `studyable()`, `isName()`, `nameCandidates()`, `sureNames()` | нет |
| уровни (HSK, позже A1–C2) | `levels: WordLevels` | нет |
| знакомые сочетания | `knownByParts()`, `expandKnown()` | нет |
| поиск | `searchForm()`, `isReadingQuery()`, `readingMatches()` | нет |
| словарь книги | `analyze()` (по умолчанию через `chapter()`) | нет |

Китайский (`ZhEngine`) — первый модуль. Через розетку идут: построение главы, озвучка, язык
карточек, знакомые слова, статистика книги, рекомендации, поиск, анализ книги, проверка
вставленного текста. Тест `LanguageModuleTest` проверяет, что пробный «испанский» модуль из
одних обязательных частей работает со всем этим без доработок. Внешне приложение не меняется.

Осталось китайским: карточка слова в читалке (разбор иероглифов, чтения многозначных
иероглифов, источник перевода) и выбор HSK 2.0 / 3.0 в библиотеке. Их удобнее делать
отдельно для каждого языка на шаге 2.

## Шаг 2: испанский

Язык выбирается в библиотеке («Язык: … · Сменить»), приложение перезапускается со словарём
выбранного языка. У каждой книги свой язык (определяется при импорте), библиотека показывает книги
текущего языка. Карточки, уровень и настройки повторения — у каждого языка свои.

| Часть | Как сделано |
|---|---|
| Слова | `es/EsEngine.kt`: последовательности букв (с апострофом и дефисом внутри слова) |
| Начальная форма | таблица форм английского Викисловаря: hablo/habló → hablar, controlada → controlar; частые формы глаголов сначала как глагол (era, son → ser); приклеенные местоимения снимаются правилом: dámelo → dar |
| Словарь | `assets/es/dict.tsv`: 112 тыс. слов; русские значения у 25,2 тыс.: 15,8 тыс. из русского Викисловаря и 9,3 тыс. частых слов машинным переводом английских значений (`tools/translate_es_ru.py`, `data/es/ru_ai.jsonl`, в карточке слова подписано); у остальных английские. 502 тыс. форм. Сборка: `tools/build_es_dict.py` |
| Частотность и уровни | ранг по субтитрам (FrequencyWords, CC BY-SA 4.0), суммированный по формам; уровни A1–C2 по частотности (500 / 1 500 / 3 000 / 5 000 / 8 000 / 16 000 слов) — приблизительные, так и подписано |
| Выражения | 17,5 тыс. выражений Викисловаря: нажатие на слово внутри выражения (sin embargo) показывает выражение и даёт выделить его целиком |
| Карточка слова | слово → начальная форма, часть речи и грамматика формы, русские и английские значения, источник перевода; в карточки сохраняется начальная форма; в упражнении скрывается форма из предложения |
| Вёрстка | без строки пиньиня; при выравнивании растягиваются только пробелы; переносы по слогам (`es/EsHyphenator.kt`) |
| Знакомые слова | «Знаю» и уровень ставятся на начальную форму; все её формы считаются знакомыми; имена (с заглавной, не из словаря) не подчёркиваются |
| Статистика книги | слова считаются по начальным формам; сложность по уровням A1–C2 |
| Озвучка, поиск, TXT | испанский голос; поиск без регистра и ударений; TXT не в UTF-8 — Windows-1252, главы «Capítulo N» |

На книге в 132 тыс. слов: в словаре 98,2% слов текста, с русским значением 95,1% (остальное в
основном имена).

Ещё не сделано: проверка испанского режима вживую на телефоне (эмуляторы гоняют китайский сценарий),
язык книги в резервной копии (после восстановления на другом телефоне книги считаются китайскими),
решение о выпуске (одно приложение или отдельное).

## Ветка `amauta`: испанский и китайский в одном приложении (0.23.0)

Ветка `es` с влитой китайской веткой (`ccr-07faeaac-ez9x94`, 0.22.0). Название и значок — Amauta Reader,
идентификатор `com.hanreader.app.es` (обновление испанского приложения, не HanReader).
- `BuildConfig.LANGUAGES = "es,zh"`: приложение открывается на испанском, в библиотеке есть «Язык: … · Сменить».
  `Languages.AVAILABLE` идёт в порядке из настройки сборки (первый — язык по умолчанию).
- Китайские словари (`assets/zh`) и шрифты (Noto SC, LXGW WenKai, Zhuque Fangsong) снова в APK: отладочный APK 44,7 МБ.
- Доработки, перенесённые раньше вручную в обе ветки, сведены в одну версию через розетку: «Итог главы»
  (для китайского выражения — чэнъюи и пословицы), своё значение здесь / в книге / везде (для китайского
  значение в книге заменяет все чтения слова), подсказки, сноски.
- Из китайской ветки: счётные слова и метка идиомы в карточке, китайские имена в анализе книги
  (версия анализа 4 — книги пересчитываются), словарь 0.20–0.21, голос с сервера.

Ещё не сделано: язык книги в резервной копии, проверка обоих языков вживую на телефоне.
