# Языковая «розетка» (экспериментальная ветка)

Эта ветка — эксперимент с другими языками. Основная ветка и бета её не видят:
сборка здесь публикует только артефакт в Actions, не бету, а приложение ставится
отдельно (`com.hanreader.app.es`, «HanReader ES»), не трогая книги и слова в основном HanReader.

## Что сделано (шаг 1)

`lang/LanguageModule.kt` — общий интерфейс языка. Обязательное — только основа,
остальное имеет нейтральные значения по умолчанию:

| Часть | Где | Обязательно |
|---|---|---|
| описание языка: тег для карточек и озвучки, название, «строка над словом», уровни, конец предложения, буквы языка | `LanguageInfo`, `Languages` | да |
| разбивка абзаца на слова + строка над словом | `chapter()` → `PreparedText` | да |
| короткий перевод над словом, перевод для карточки | `glossShort()`, `cardTranslation()` | да |
| чтение для карточки (пиньинь) | `reading()` | нет |
| что стоит учить, имена | `studyable()`, `isName()`, `nameCandidates()`, `sureNames()` | нет |
| уровни (HSK, позже A1–C2) | `levels: WordLevels` | нет |
| знакомые сочетания | `knownByParts()`, `expandKnown()` | нет |
| поиск | `searchForm()`, `isReadingQuery()`, `readingMatches()` | нет |
| словарь книги | `analyze()` (по умолчанию через `chapter()`) | нет |

Китайский (`ZhEngine`) — первый модуль. Через розетку идут: построение главы, озвучка, язык
карточек, знакомые слова, статистика книги, рекомендации, поиск, анализ книги, проверка
вставленного текста. Тест `LanguageModuleTest` проверяет, что пробный «испанский» модуль из
одних обязательных частей работает со всем этим без доработок. Внешне приложение не меняется.

Осталось китайским: карточка слова в читалке (разбор иероглифов, чтения многозначных
иероглифов, источник перевода) и выбор HSK 2.0 / 3.0 в библиотеке. Их удобнее делать
отдельно для каждого языка на шаге 2.
