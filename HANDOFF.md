## DeepSeek: надёжность и экономия — 0.34.0

- **Дневной лимит** вместо «за сеанс»: `AiUsage.day`, `AiUsageStore` (prefs `context_ai_usage`),
  по умолчанию 100/день (1–1000, ключ `daily_limit`), обнуление в полночь (`refreshUsage`).
- **Частичное принятие:** `AiContext.read` → `AiParsed(rows, problems, rejected)`; плохая строка
  отклоняет только своё слово. Весь ответ отвергается при не-JSON / обрезке / нуле годных строк.
- **Один запрос на экран:** `AiRepository.checkVisibleGroup` пакует слова всех видимых абзацев
  (≤20) в `AiContext.groupJson` (`paragraphs`, `term_id` с префиксом `p<i>:`), ответ режет
  `splitGroup`. Ручная проверка и одиночный абзац — прежний формат.
- **Меньше токенов:** `sentence` только для повторяющегося слова, `lemma` только если отличается,
  без дублей соседнего контекста; `max_tokens` 8000, пояснение до 200 символов.
