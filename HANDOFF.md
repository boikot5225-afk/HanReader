## Что это за приложение

Android-читалка китайских книг (Kotlin, Jetpack Compose, Room), выросла из Lexicon. Всё офлайн, без разрешения на интернет.
Основное: EPUB/FB2/TXT/DOCX/DOC, вставка текста и «Поделиться»/меню выделения; свой движок: сегментация Jieba-подобная (`zh/ZhSegmenter.kt`), пиньинь над словами на Canvas (`reader/RubyText.kt`), разбивка на страницы (`reader/Pagination.kt`); словари CC-CEDICT + русский Викисловарь + машинный перевод DeepSeek (`assets/zh/ru_ai.tsv`, `ru_chars.tsv` — значения иероглифов по чтениям); HSK-уровни, «Знаю/Не знаю», рекомендации i+1, подсказки над словами (угасают после 3 встреч), карточки SRS, выделения и заметки, чтение вслух (TTS по предложениям), статистика (серия, минуты, прочитано знаков, понимание книг), оценка сложности книги, цвета тонов, упрощённые/традиционные (OpenCC), свои значения слов, ручное разделение склеенных слов, полная резервная копия ZIP, отчёты о сбоях (локально, отправка вручную), экран «О приложении» с лицензиями.

База Room: **версия 13** (схемы в `app/schemas`, `MigrationTest` поднимает базу с версии 4).

## Сборка и тесты (облачная среда)

- Окружение «HanReader Android»: доступ к dl.google.com, kaikki.org; секрет для api.deepseek.com сохранён в настройках среды (ключ в командах — заглушка `proxy-injected`).
- Android SDK: `/opt/android-sdk` (`local.properties`, не в git). `~/.gradle/init.d/mirror.gradle` подменяет Maven Central на зеркало Google; `~/.gradle/gradle.properties` — `robolectricRepoUrl`. В новой среде их может не быть — восстановить по необходимости.
- Тесты: `gradle :app:testDebugUnitTest --offline -q` (155 тестов, 6 пропускаются: замеры на книгах и скриншоты для магазина). Robolectric; скриншоты UI рисуются через `decorView.draw`.
- APK: `gradle clean :app:assembleDebug --offline -q` (всегда `clean`).

- 须 в значениях иероглифов — только «должен» (нет «борода»): точечно дописать в `ru_chars.tsv` при необходимости.
