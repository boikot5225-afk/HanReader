# 汉读 HanReader

Android-приложение для чтения китайских книг и изучения слов: читаешь EPUB → нажимаешь на слово →
слово вместе с предложением из книги попадает в интервальное повторение.

Основа — Lexicon 0.7.0 (карточки, SRS, письмо, TTS, резервные копии). Читалка — новый нативный движок,
без WebView.

## Движок чтения

| Часть | Как сделано |
|---|---|
| EPUB | `epub/EpubBook.kt`: container.xml → OPF → spine, оглавление из EPUB3 nav или NCX, глава → абзацы / заголовки / картинки (Jsoup) |
| Словарь | `assets/zh/lexicon.bin`: 121 тыс. статей CC-CEDICT + 69 тыс. слов Jieba; двоичный файл с готовой хеш-таблицей (`tools/build_lexicon_bin.py` из `data/zh/lexicon.dat`), при первом запуске копируется из APK и дальше отображается в память — без разбора при старте; русские значения, HSK и имена догружаются в фоне |
| Сегментация | `zh/ZhSegmenter.kt`: модель Jieba без HMM — граф слов словаря + динамическое программирование по частотам |
| Пиньинь | основное чтение слова или иероглифа из pypinyin, иначе из CC-CEDICT; три режима: над всеми, только над незнакомыми, выключен |
| Знакомые слова | таблица `known_words`: «Знаю» в карточке слова и отметка всех слов до уровня HSK 3.0 / 2.0; выученные карточки (30+ дней) тоже считаются знакомыми; в конце раздела — доля знакомых слов |
| Отображение | `reader/RubyText.kt`: абзац рисуется на Canvas, пиньинь над словами, касание определяется по координатам; `LazyColumn` собирает только видимые абзацы |
| Оформление | `Appearance.kt`: темы «Нуар», «Неонуар», «Классика», «Бумага» и «Авто» (днём «Бумага», ночью «Нуар») для всего приложения; лист «Оформление» в читалке: тема, шрифт иероглифов (Noto Serif SC, Noto Sans SC, LXGW WenKai, Zhuque Fangsong, системный), размер, межстрочный интервал, отступ абзацев, поля, размер пиньиня, выравнивание по ширине, красная строка |
| Режимы чтения | `reader/Pagination.kt`: страницы (по умолчанию) или прокрутка. Глава режется на страницы по строкам абзацев, абзац переходит на следующую страницу, картинка вписывается в страницу; позиция хранится как глава + абзац, поэтому смена шрифта не сбивает место. Листание: свайп, касание по краю (левая/правая треть), кнопки громкости; касание по слову — карточка слова |
| Полноэкранное чтение | системные панели скрыты; касание в центр показывает меню поверх текста (страница не пересчитывается): ползунок по разделу, «стр. N из M», «≈ X мин» по личной скорости чтения, разделы, оглавление, доля знакомых слов, яркость; экран не гаснет |
| Навигация | панель «Оглавление · Закладки · Поиск»; закладки (таблица `bookmarks`, Room v7) ставятся значком в меню и видны лентой в шапке страницы; поиск по всей книге (`reader/BookSearch.kt`): иероглифы как подстрока или пиньинь без тонов по слогам (dianhua находит 电话 и внутри 打电话, полифоны читаются по слову), найденное место подсвечивается; после перехода по оглавлению, поиску, закладке или ползунку — плашка «← Вернуться» |
| Форматы и библиотека | EPUB, FB2, FB2.ZIP, TXT, DOCX, DOC (`epub/BookSource.kt`, `epub/WordBooks.kt`: DOCX — абзацы, заголовки по стилям, картинки; DOC — текст из двоичного формата Word 97–2003 без сторонних библиотек): формат определяется по содержимому; TXT — UTF-8/UTF-16/GB18030, главы по заголовкам 第…章/回/卷, 序章, Chapter N, иначе части по ~6000 знаков. Обложки из EPUB/FB2 (для TXT рисуется своя), сетка или список, сортировка; книги открываются из файлового менеджера и Telegram («Открыть с помощью», «Поделиться») |
| Подсказки в тексте | включаются в «Оформлении»: красная линия — незнакомые слова, синяя — рекомендуемые (`reader/Recommendations.kt`): незнакомые слова с частыми повторами в книге и уровнем чуть выше твоего («i+1»); уровень — выбранный HSK (HSK 2.0 пересчитывается на 3.0) или определённый автоматически (самый высокий уровень HSK 3.0, известный на 80%); число на раздел настраивается; режим пиньиня «только над рекомендуемыми» |
| Имена собственные | словарь `zh/names.tsv` (~69 тыс. имён людей, мест и организаций из разметки Jieba, отфильтрованной по форме имени); имена, найденные в книге, и отмеченные кнопкой «Это имя» (таблица `user_names`, Room v8, во всех книгах) не подчёркиваются, не рекомендуются, не учитываются в процентах и не режутся сегментатором |
| Словарь книги | после импорта книга один раз разбирается в фоне (`reader/BookVocabulary.kt`, таблица `book_words`): доля знакомых слов, покрытие текста уровнями HSK 3.0, самые частые незнакомые слова; транслитерированные имена распознаются и не учитываются |
| Подготовка к разделу | в начале раздела — доля знакомых и число незнакомых слов; по кнопке — 10/20/30 самых частых незнакомых слов раздела в карточки с предложением из текста |
| Знакомые сочетания | `KnownMatcher`: слово вне HSK считается знакомым, если это сочетание знакомых слов без собственного значения (一个人) или знакомое слово + частица/дополнение (看着, 跑进) |
| Слово → карточка | `CardDao.saveFromReader`: новая карточка или новый пример к существующей, источник (книга, глава, предложение) в таблице `word_sources` |

Замеры на компьютере (JVM), книга ~2 млн знаков, 248 разделов: открытие EPUB 98 мс, самый тяжёлый раздел
разбирается и сегментируется за 37 мс, анализ словаря всей книги — около 2 с. На телефоне ожидается в несколько раз медленнее — это и проверяем.

## Известные ограничения прототипа

- Русские значения: русский Викисловарь (11,7 тыс. слов) и машинный перевод CC-CEDICT (95 тыс. статей, DeepSeek, лексикографом не проверялся). Вместе закрывают ~91% текста романа и 918 из 1000 его самых частых слов (остальное в основном имена); для остальных — английский CC-CEDICT. В карточке слова подписан источник русского значения.
- Оформление издателя (шрифты, таблицы, CSS) упрощается.
- Чтение многозначного иероглифа, стоящего отдельно, не зависит от контекста (地 всегда dì).
- Сегментация: 14 из 17 регрессионных случаев Reader AI (`app/src/test/resources/zh_lexical_regressions.json`).
  Неверные границы можно поправить вручную в карточке слова (кнопки «← +», «−», «+ →»).

## Сборка

JDK 17, Gradle 8.13+, Android SDK 36.

    gradle :app:testDebugUnitTest :app:assembleDebug

Тесты включают сквозной сценарий в Robolectric (импорт → открытие → сохранение слова) и рендер абзаца
в `app/build/screens/ruby.png`. Замер на своей книге:
`HANREADER_TEST_EPUB=/путь/книга.epub gradle :app:testDebugUnitTest` (печатает только цифры).

Отладочные APK подписаны общим ключом `app/debug.keystore`, поэтому ставятся поверх друг друга.
Релизная подпись — см. [SIGNING.md](SIGNING.md).

Данные пересобираются так:
`python3 tools/build_zh_dict.py zh_dict_core.json zh_vocab_frequency.txt.gz jieba/dict.txt pypinyin/ data/zh/lexicon.dat` и `python3 tools/build_lexicon_bin.py data/zh/lexicon.dat app/src/main/assets/zh/lexicon.bin`
и `python3 tools/build_hsk.py complete.min.json app/src/main/assets/zh/hsk.tsv`.

Схемы базы каждой версии лежат в `app/schemas`; `MigrationTest` поднимает базу 0.1.0 и проверяет переход на текущую версию.
