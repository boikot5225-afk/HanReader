# Английский в Amauta Reader — 0.25.0

Ветка `amauta`, versionCode 66, пакет `com.hanreader.app.es` сохранён.
В библиотеке можно нажать «Сменить» рядом с языком и выбрать «Английский».
Испанский остаётся языком по умолчанию; книги и данные прежних языков сохраняются.

## Подключено

- Английский определяется по тексту при импорте. Старые TXT читаются как Windows-1252,
  EPUB и остальные поддерживаемые форматы используют общий движок.
- Английские страницы с темами, шрифтами и подсказками; без строки пиньиня.
- Карточка слова с исходной формой, частью речи, IPA, русскими и английскими значениями,
  источником русского перевода и основными формами глагола.
- Словоформы (`went → go`, `children → child`), варианты написания (`organise → organize`),
  притяжательные формы и сокращения.
- Соседние выражения (`looked up → look up`): одна подсказка, предложение выделить выражение,
  сохранение словарной формы выражения в карточку.
- «Знаю», свои значения, поиск без регистра с нормализацией апострофа, анализ словаря книги,
  рекомендации и итог главы. Уровни A1–C2 приблизительные, по частотности, не официальный CEFR.
- Карточка сохраняет исходное слово, IPA/часть речи и предложение из книги. В упражнении
  загруженный движок скрывает изменённые формы и выражения, например `went` или `looked up`.
- Системный английский голос Android. Китайский нейросетевой голос не используется для других языков.

Произношение исходного слова показано рядом с ним: для `went` карточка показывает `→ go`
и IPA слова `go`; кнопка озвучки выбранного слова читает именно `went`.

## Сохранность данных

Английский добавлен в конец `Languages.ALL`, поэтому даты статистики китайского и испанского
не меняют ключи. Отметки, значения и карточки уже хранят язык, дополнительной миграции Room нет.

Проверка резервной копии обнаружила, что прежний фильтр дат принимал только обычные даты
и отбрасывал ключи статистики с языковым сдвигом. Теперь принимаются корректные даты всех
трёх языков. Проверены независимые карточки с одинаковым написанием и переводом в английском
и испанском, отметки, свои значения, язык книги и восстановление статистики.

## Проверка

Полный прогон:

```sh
HANREADER_EN_AUDIT_SOURCE=/workspace/HanReader/.work/en-dictionary/sources \
python3 /workspace/toolchains/run-gradle.py clean :app:testDebugUnitTest :app:assembleDebug \
  -ProbolectricRepoUrl=https://maven-central.storage-download.googleapis.com/maven2/
```

BUILD SUCCESSFUL: 351 тест, 344 успешно, 7 пропущены. Включены существующие китайские
и испанские проверки. Для публичных книг исходники нужны локально; без переменной окружения
корпусная проверка пропускается. Python-проверок источников и сборщика — 14, все прошли.

Проверки настоящей Compose-карточки подтверждают сохранение `go` из `went` вместе с IPA
и исходным предложением, сохранение полного раскрытия `I'd`, сохранение `look up` из
`looked up`, кнопку «Знаю» у сокращения и выражения, отсутствие испанских настроек в английском.

Дополнительно новый движок подготовил обе книги Gutenberg целиком. Для каждого абзаца
проверены непрерывность токенов и совпадение смещений с исходным текстом.

## Что ещё требует доводки

- Разделённые фразовые глаголы, например `turn it off`, ещё не объединяются.
- Локальные правила выбирают часть речи в некоторых простых случаях (`a saw` / `I saw`),
  но общего выбора любого значения по контексту нет. Полные варианты остаются в карточке.
- Неоднозначные сокращения сохраняют альтернативы. Для `I'd read` нельзя уверенно выбрать
  had или would; для части сокращений пока показывается раскрытие, без русского контекстного перевода.
- Качество первых значений и распознавания выражений нужно проверять по чтению книг.
- Реальная проверка английского режима на телефоне и его озвучки ещё не выполнена.
