# Википедия из выделения — первый этап, 0.27.0

В карточке слова и меню выделенного выражения добавлена кнопка «Найти в Википедии».
Новая панель открывается с редактируемым запросом. До нажатия «Найти» запрос не уходит.
Доступны русский язык и язык книги (es/en/zh); пользователь выбирает статью из результатов.
Панель показывает вступление статьи, а не сгенерированное определение. Его можно
отредактировать и сохранить в заметки. Межъязыковой переход использует langlinks
Wikimedia и сохраняет соответствие статье, а не переводит название автоматически.
Страница неоднозначности отмечается и не сохраняется как определение.

## Архитектура

- `wiki/Wikipedia.kt`: прямые анонимные HTTPS-запросы к официальному Action API
  `https://{ru,es,en,zh}.wikipedia.org/w/api.php`, идентифицирующий User-Agent,
  поиск в основном пространстве имён, получение вводного текста и номера версии,
  межъязыковые ссылки. Ни сервера проекта, ни ИИ/API-ключа нет. В сеть передаётся
  запрос пользователя; предложение и остальной текст книги в HTTP-запрос не входят.
- Кеш в `noBackupFilesDir/wikipedia-v1`: SHA-256 от типа запроса, языка и запроса/ID;
  валидированные JSON, атомарная запись, максимум 100 записей, один запрос за раз.
  Повторные неизменённые поиски/статьи используют кеш, включая после перезапуска.
  Некорректные ответы и ошибки не считаются успешным кешем. Кеш не входит в backup.
- Сохранение через существующие `Highlight` и `highlightDao`; схемы/миграции БД,
  формата резервных копий и второго словаря не требуется. Привязка: ID книги,
  глава, абзац, начало/конец выделения. Координаты экрана и размер шрифта не используются.
- Заметка содержит термин, описание, предложение из книги, название статьи,
  permalink версии, ссылку на историю авторов, CC BY-SA 4.0 и дату получения.
  Редактирование описания отмечается. Ручная заметка того же выделения сохраняется:
  описание добавляется к ней, а не перезаписывает её. Повторное сохранение без изменений
  не дублирует запись. Удалённая/закрытая/изменившаяся книга не получает чужую заметку.
- Список/редактирование/удаление уже доступны в оглавлении → «Выделения».
  Существующий экспорт Markdown/системное «Поделиться» и backup включают новые заметки
  как обычные выделения. Сохранённые заметки не зависят от сети или очистки кеша.

## Ограничения первого этапа

Пока показываются только вводные абзацы без полной статьи, картинок и формул.
«Открыть оригинал» ведёт на соответствующую версию в браузере. Нет ленты новостей,
импорта полной статьи или автоматического выбора понятия по тексту книги.
Кешированные описания не обновляются автоматически; новую версию можно посмотреть
в браузере. Кеш не является постоянно доступной офлайн-энциклопедией: записи вытесняются.
Сохранённая заметка остаётся локально и не заменяется при изменении Википедии.

## Проверки

Мокированные тесты: структура поиска/статьи, санитарная обработка HTML-сниппетов,
межъязыковые ссылки, неоднозначность, ошибки/некорректный JSON, дедупликация запросов,
повторное открытие кеша без сети; панель без автоматического запроса, редактирование
описания/сохранение/атрибуция, повтор после сетевой ошибки; сохранение ручной заметки,
отсутствие дублей, повторное открытие книги, Markdown и backup, отказ после закрытия книги.

`WikipediaLiveTest` запускается отдельно с `HANREADER_LIVE_WIKIPEDIA=1` и без ключа.
Реальный клиент в Robolectric успешно получил поиск и вступления en/es/zh, а также
русскую версию через langlinks. Это проверка реального API из среды разработки,
не проверка на физическом телефоне. Обычный CI не зависит от сети Wikimedia.
Итоги прогонов, сборки и доставки — в HANDOFF.md.
