# Пробные книги — 0.26.9

В библиотеку добавлено пробное чтение на выбранном языке:

- Испанский: **La llave del jardín** — «Ключ от сада».
- Английский: **A light at the station** — «Огонёк на станции».
- Китайский: **雨后的信** — «Письмо после дождя».

Это три оригинальных коротких рассказа проекта по CC0 1.0, по три главы каждый.
Исходники: `data/demo_books/*.json`, описание прав: `data/demo_books/README.md`.
`python3 tools/build_demo_books.py` собирает детерминированные EPUB 2 в
`app/src/main/assets/demo/`. Все три файла вместе занимают около 11 КБ.
Ни одна пользовательская книга в комплект не включается.

В пустой библиотеке есть карточка с названием рассказа, пояснением и кнопкой
«Читать пробную книгу». В заполненной библиотеке остаётся компактная кнопка
«Открыть пробную книгу» рядом с добавлением собственных файлов. Выбирается рассказ
текущего языка; язык переключается прежней кнопкой «Сменить».

Добавление происходит только по нажатию. APK уже содержит текст: скачивания,
регистрации, API-ключа и платного запроса для пробного чтения не требуется.
Существующий EPUB-импорт проверяет книгу, добавляет обычную запись в ту же Room-базу
и определяет язык. Читалка, словарь, карточки, прогресс и исправления работают через
прежние механизмы. Конфигурация ИИ не включается автоматически.

Стабильное имя файла определяет уже добавленный экземпляр, в том числе после
восстановления резервной копии. Повторные и одновременные нажатия, включая разные окна приложения,
возвращают его ID, не сбрасывая прогресс. Потерянный файл восстанавливается из assets
с тем же ID. После удаления книги читатель может добавить её снова. Самостоятельно
после удаления она не появляется.

Схема базы и формат резервной копии не меняются. Исходный текст редакции v1 не следует
менять без смены имени редакции: это сохраняет привязку прогресса и контекстных значений.

## Проверки

DemoBooksTest проверяет структуру EPUB/текст всех глав/оглавление/определение языка;
настоящую кнопку библиотеки, открытие страниц, русские значения и сохранение карточки
на каждом из трёх языков без ИИ-запросов; повторное/одновременное добавление;
позицию после нового ViewModel; сериализацию резервной копии; восстановление файла
и повторное добавление удалённой книги. Снимки тестового интерфейса — `build/screens/demo-*`.
Сборка EPUB повторена с проверкой одинаковых SHA-256.

Это проверки Robolectric с нативным рендерингом. Физический телефон и платный API
не использовались. Итог целевых тестов и сборки фиксируется в HANDOFF.md.
