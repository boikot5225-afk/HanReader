# Английский EPUB: открытие и отзывчивость — 0.25.1

Пользователь сообщил о зависании при открытии уже импортированного английского EPUB
и замедлении приложения. Конкретный EPUB не предоставлен.

## Найденная причина

`ReaderScreen` синхронно вызывал `Recommendations.level`. Ленивое построение уровней
английского движка обходило и декодировало весь `dict.tsv` (около 102 тысяч ключей,
44 МБ) в потоке интерфейса. Предыдущие проверки движка и карточки не проходили через
полный экран читалки и не обнаружили этот путь.

Теперь сборщик сохраняет `ranks.tsv`: 16 494 строки, 211 581 байт. Индекс уровней
готовится при фоновой загрузке движка, без сканирования словарных статей на экране.
Манифест обновлён до формата 2; основные статьи и формы не изменены.

## Другие исправления

- Расчёт знакомых слов, покрытия, рекомендаций, подсказок и итога главы идёт в фоне.
- Пустой список знакомых слов не запускает словарные запросы; обычные слова не проходят
  лишний разбор сокращений. Проверка наличия ключа TSV не декодирует его JSON.
- Лексический кеш движка не удерживает свой замок во время декодирования статьи.
- Анализ книги использует один параллельный исполнитель. Алфавитная глава после анализа
  больше не пересобирается без необходимости.
- При выходе загрузка отменяется; построение главы проверяет отмену между блоками.
- При ошибке открытия показывается сообщение и доступна кнопка «Назад».
