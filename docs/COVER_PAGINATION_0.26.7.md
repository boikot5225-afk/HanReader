# Вечная загрузка обложки EPUB — 0.26.7

На записи после выбора китайского EPUB «阿Q正传» экран более минуты показывал один
индикатор загрузки. Переданный файл — 287 118 байт, 15 разделов; первые два содержат
только изображения. Текстовые главы небольшие, изображения обложек 600 × 800.
Сам файл не повреждён. Книга остаётся локально в пользовательских вложениях и не
включается в репозиторий, CI-артефакты или APK.

## Причина

После открытия китайской книги фоновый анализ слов и имён вызывает пересборку текущей
главы. У главы, содержащей только обложку, новый `ChapterContent` может быть равен
старому по всем полям (включая одинаковое время сборки, округлённое до миллисекунд),
но является другим объектом.

`produceState(..., chapter, ...)` сравнивал ключи по `equals`. Для равной главы
повторная подготовка страниц не запускалась. Однако готовый результат проверялся
через `result.chapter === currentChapter`. Эта проверка возвращала false для нового
объекта, и экран навсегда переходил в ветку индикатора, хотя страницы были готовы.

Ошибка воспроизведена отдельным UI-тестом до исправления: страница `1 / 1` сначала
появляется, затем исчезает после замены главы на `chapter.copy()` вместе с обновлением
`analyzedTokens` — как при завершении фонового анализа. После исправления тест проходит.

## Исправление

Подготовка и принятие страниц используют один запомненный `layoutKey`. Он зависит от
книги, открытого источника, содержимого главы, параметров страницы и метрик шрифта.
Равная по содержимому пересобранная глава сохраняет ключ и готовые страницы.
Другая книга, изменённая глава или геометрия получают новый ключ: устаревшие страницы
не показываются. EPUB, сегментация, порядок глав, сохранённые позиции и ИИ-кеш не меняются.

## Проверки

- `EqualChapterPaginationTest`: до исправления воспроизвёл исчезновение готовой обложки;
  после исправления проходит. Это самодостаточный тест без пользовательской книги.
- `UploadedChineseOpeningTest`: настоящий EPUB → импорт → обложка → завершение анализа
  книги → сохранение готовой страницы → первая текстовая глава. В CI без локального
  вложения этот дополнительный тест пропускается.
- `GlossStabilityTest` и `SceneSpacingTest`: прежние проверки стабильности страниц и
  интервалов между сценами проходят.
- Итог целевого прогона: 7 тестов, все успешны. У переданного EPUB: импорт 373 мс,
  подготовка главы 261 мс, первая пагинация 1458 мс; обложка остаётся доступной после
  анализа, переход к текстовой главе 97 мс, её пагинация 693 мс.

Время получено в Robolectric с нативным рендерингом, не на физическом телефоне.
Платные запросы DeepSeek не выполнялись. Серверная озвучка остаётся отключённой.
