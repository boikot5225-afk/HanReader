Политика конфиденциальности HanReader

Действует с 9 ноября 2026 года.

HanReader — приложение для чтения китайских книг и изучения слов. Оно работает на телефоне без интернета и не собирает персональные данные. Интернет нужен только нейросетевому голосу, если ты сам его включишь.

Какие данные есть в приложении

  • Книги, которые ты добавляешь, места чтения, закладки, выделения и заметки.
  • Слова в карточках, их примеры и прогресс повторения, отметки «Знаю» / «Не знаю».
  • Статистика чтения: время и количество прочитанных знаков по дням.
  • Настройки оформления и чтения.

Всё это хранится только на твоём устройстве, в закрытой папке приложения.

Что передаётся наружу

  • Ничего не отправляется автоматически. В приложении нет рекламы, аналитики и сторонних трекеров. Разрешение на доступ к интернету используется только нейросетевым голосом (ниже); по умолчанию он выключен.
  • Нейросетевой голос (по желанию: «Чтение вслух → Голос → Нейросетевой голос»). Чтобы озвучить предложение или слово, приложение отправляет на сервер HanReader только этот текст, название выбранного голоса и скорость. Имя, аккаунт, идентификатор устройства, книги и другие данные не передаются. Сервер, как любой сайт, видит IP-адрес запроса. Присланный текст используется только для озвучки. Готовые записи хранятся в кэше приложения на телефоне, чтобы не скачивать их повторно. Если голос выключен, приложение не обращается к сети.
  • Резервная копия сохраняется в файл, который ты сам выбираешь, и никуда не отправляется.
  • Отчёты о сбоях сохраняются на устройстве. В них только версия приложения, версия Android, модель телефона и техническое описание ошибки — без текста книг и слов. Отчёт отправляется, только если ты сам нажмёшь «Отправить» и выберешь, куда: приложение открывает системное меню «Поделиться».
  • Чтение вслух голосом телефона использует синтезатор речи, установленный в Android (например, Google). Текст передаётся этому синтезатору на устройстве; как он обрабатывается, определяет политика его разработчика.
  • При системном резервном копировании Android данные приложения могут сохраняться в облаке твоего аккаунта Google по настройкам самого телефона.

Удаление данных

Все данные удаляются вместе с приложением или через «Настройки Android → Приложения → HanReader → Очистить данные». Отчёты о сбоях можно удалить в настройках приложения.

Дети

Приложение не собирает данные ни о ком, включая детей.

Изменения

Если приложение начнёт передавать другие данные (например, для новых онлайн-функций), эта политика будет обновлена до выхода такой версии.
