## Серверная озвучка

По указанию владельца удалены `NeuralVoice.kt`, HTTP-клиент озвучки, предзагрузка
звука, настройки сервера и выбор сетевого голоса. В BuildConfig и CI больше нет
`VOICE_URL`, `VOICE_TOKEN` или токена серверной озвучки. Ни чтение вслух, ни кнопки
слов не читают старые настройки `neural_voice`.

Остаётся Android TextToSpeech для испанского, английского и китайского. Сеть и
офлайн-голоса зависят от установленного синтезатора Android. Разрешение INTERNET
сохранено для отдельно включаемого пользователем DeepSeek. Ключ DeepSeek в APK не входит.

## Подпись и перенос

Сохраняется постоянный RSA-4096 сертификат, проверенный по прежнему подписанному APK
0.25.1 того же пакета. SHA-256 сертификата:

`59345a3b2a7007d83b95832fe30e120fb71686c413680ed86fb078f813d97859`

Закрытый ключ остаётся в GitHub Actions; в рабочую среду и Git он не извлекался.
CI проверяет сертификат, отсутствие debuggable и выравнивание APK на 16 КБ.
Это не является подтверждением модерации RuStore.

Прежние выдаваемые пользователю APK подписаны общедоступным тестовым ключом.
Устанавливать production APK поверх них Android не разрешает. Порядок перехода:

1. Установить **debug 0.26.4** поверх прежнего debug.
2. Сохранить резервную копию во внешний файл и убедиться, что он сохранён.
3. Затем удалить debug и установить production APK.
4. Восстановить архив. Ввести ключ DeepSeek заново; ИИ включить по желанию.

Не удалять прежнее приложение до экспорта из 0.26.4: старые архивы не содержали ИИ-кеш.

## Архив формата 4

`BackupFormat`, `LexiconViewModel` и `AiCheckDao` расширяют существующий ZIP/JSON,
не создавая второй словарь. Экспорт читает данные одним снимком транзакции Room.
Сохраняются все состояния `ai_checks`: checked, accepted, proposed, rejected.
Проверяются привязка к книгам, уникальность ключей, хеши, диапазоны, переводы и состояния.
Повреждённый раздел отвергается до изменения базы.

Восстановление книг и ИИ-записей выполняется одной транзакцией. Исходные book ID,
contextHash и cacheKey сохраняются. Для неизменённых контекста, модели и базовых
значений прежние проверки используются без новых API-запросов. Более старые архивы
1–3 читаются, но отсутствующие в них ИИ-результаты восстановить нельзя.
API-ключ и флаги включения ИИ не экспортируются. Ручные значения сохраняют приоритет.
