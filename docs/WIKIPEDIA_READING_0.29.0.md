# Чтение полных статей Википедии — 0.29.0

В карточке найденной статьи появилась кнопка «Читать статью целиком». В библиотеке —
«Википедия · читать и сохранять статьи», поиск и список офлайн-копий. Открытие статьи
не закрывает исходную книгу и не переключает язык приложения. Озвучка исходной книги
при открытии Википедии/заметок приостанавливается, чтобы не менять место чтения.

## Чтение и заметки

- Полная текстовая статья, заголовки разделов, переход к разделу, изменение шрифта,
  включение/выключение подсказок. Пока используется прокрутка.
- Используются прежние LanguageModule.chapter, RToken, RubyParagraph, RubyMetrics и
  KnownMatcher. Сегментация выполняется вне главного потока для видимых абзацев.
  Шрифт/тема берутся из читалки; размер статьи сохраняется отдельно и не меняет книгу.
- Русские статьи читаются без словарных подсказок. Для испанских, английских и китайских
  используется словарь текущего языка приложения. Статья другого языка открывается
  обычным текстом с предложением переключить язык в библиотеке; второй большой словарь
  параллельно не загружается. Общие ручные значения имеют приоритет. Значения отдельной
  книги/употребления в статью не переносятся.
- Нажатие на слово показывает короткое словарное значение. Долгое нажатие с движением
  выделяет фрагмент. Есть выбор всего абзаца и доступное действие выбора абзаца.
- «В заметку книги» сохраняет фрагмент через прежние saveWikipediaNote или
  saveKnowledgeWikipedia. Сохраняются контекст исходной книги, pinned oldid, авторы/
  история, CC BY-SA 4.0 и дата получения. Прежняя заметка не удаляется. Дословный фрагмент
  полной статьи не помечается как отредактированное вступление. Вход из библиотеки без
  книги не предлагает сохранение в чужую/фиктивную книгу.
- При возврате сохраняется редактируемое описание в прежнем поисковом окне. Клавиатура
  поиска при чтении скрывается. Назад закрывает статью, затем можно вернуться к книге.

## API и хранение

Официальный Action API Wikimedia: `action=parse`, `oldid`, `prop=text|revid`.
Ответ должен совпасть с ID и ревизией выбранной статьи. Новый запрос отправляет язык
и номер версии статьи; текст книги, API-ключ DeepSeek и cookies не передаются.
DeepSeek для чтения/словаря/экспорта не вызывается.

Jsoup извлекает инертные абзацы, заголовки, списки, цитаты, текст строк таблиц и базовый
текст формул. WebView/JavaScript/внешние ресурсы не используются. Навигационные блоки,
скрипты и формы удаляются; изображения/видео не загружаются. Ссылки на оригинал и историю
ведут только на официальный языковой домен Википедии с ID/oldid. Это текстовая версия,
а не точная браузерная вёрстка страницы; сложная математика и интерактивные элементы не
воспроизводятся. Внутренние гиперссылки статей пока не образуют отдельный веб-браузер.

HTTP-ответ до 2 МБ, текст до 400 тысяч знаков и 1200 блоков; большие статьи отклоняются,
не сохраняются как успешно обрезанные. Абзацы разделяются на части до 3000 знаков для
быстрого отображения без потери слов. Кеш запросов прежний, ограничен 100 файлами/20 МБ,
параллельные одинаковые запросы объединяются mutex. Нет бесконечных повторов.

Явные офлайн-копии — JSON v1 в `files/wikipedia-reading-v1/<lang>-<id>-<revision>.json`:
метаданные, лицензируемый текст и структура. До 30 копий и 20 МБ; запись атомарная через
временный файл. Их не удаляет очистка/вытеснение временного кеша. Повреждённая копия не
выдаётся за правильную и может быть восстановлена из кеша/сети с повторным сохранением.
Удаление из списка удаляет эту копию и временный кеш её полного текста.

Позиция — устойчивый индекс абзаца/раздела по ключу языка, ID, ревизии и версии структуры;
пиксели и страницы не сохраняются. Хранится в отдельных локальных настройках. Новых
таблиц/миграций Room и второго словаря нет. Книги и их ID не меняются. Офлайн-копии пока
не входят в ручной ZIP-бэкап; об этом написано в списке статей. Сохранённые в заметку
книги фрагменты входят в прежний бэкап вместе с заметками.
