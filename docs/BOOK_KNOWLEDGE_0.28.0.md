# Люди и понятия книги — 0.28.0

В меню открытой книги над оглавлением появилась кнопка «Люди и понятия».
Раздел показывает сохранённые общие записи, варианты имени/названия, прежние
заметки из Википедии и прикреплённые фрагменты. Поиск работает только по этим
данным, без повторного разбора произведения и без сетевых или платных запросов.

## Как пользоваться

1. Открыть карточку слова/выделенного названия → «Это тот же человек или термин…».
   Выбрать существующую общую запись или создать новую, как в 0.27.1.
2. Выделить нужное место → «Сохранить фрагмент о человеке или понятии…» → выбрать
   запись. Для уже связанного имени доступна кнопка «Сохранить фрагмент к записи».
   Текст предложения не становится вариантом имени: это отдельная операция.
3. Открыть «Люди и понятия» → запись. Здесь доступны объяснение, варианты,
   сохранённые фрагменты, переход к исходному месту и экспорт одной записи.
   Из карточки общей заметки есть прямой переход к записи и её фрагментам.
4. В списке доступен экспорт всех записей. Markdown передаётся через системное
   меню Android, включая прежние заметки, цитаты, главы и сохранённую атрибуцию.
5. «Отвязать, сохранив фрагмент» оставляет отдельную заметку этого места. Её можно
   прикрепить к другой записи. Удаление общей записи также не удаляет цитаты.
6. Старую заметку Википедии можно явно сделать общей записью книги или прикрепить
   к существующей. Варианты и оригинальные заметки при этом не удаляются.

Объяснение из Википедии можно добавить прямо из списка. Сохранённые объяснения
доступны офлайн; новый поиск выполняется только по нажатию. Ссылка на источник
открывает сохранённую ревизию. При сохранении определения из текста для уже
известной общей записи автоматически сохраняется и выбранное место в книге.

## Хранение

Используется существующая таблица Room `highlights`, а не отдельный словарь.
Общие записи и варианты имени остаются в прежнем формате. Room 16 → 17 добавляет
две строки с пустым значением по умолчанию:

- `entityName`: каноническое название общей записи той же книги;
- `contextQuote`: сохранённый фрагмент текста (до 5000 знаков).

Для адреса используются `bookId/chapterIndex/blockIndex/startChar/endChar`.
Размер шрифта, страницы и координаты экрана в него не входят. Переход использует
символьную позицию и подсвечивает исходное выделение. Повторное сохранение того
же места для той же записи обновляет связь без дубликатов; существующая личная
заметка и цвет сохраняются. Можно отнести одно место к разным общим записям.

Связь хранится через написание, поскольку восстановление backup перенумеровывает
Room PK выделений. Явные варианты имени разрешаются через прежний `EntityLinks`.
Автоматический вывод фамилии из соседнего полного имени не применяется к старым
заметкам по всей книге. Только старые заметки Википедии без новой метаинформации
могут сопоставляться с единственной точной записью или явным вариантом названия.
Ручная отвязка сохраняет `contextQuote`, исключая такое повторное сопоставление.

Backup v7 сохраняет обе строки и читает прежние версии с пустыми значениями.
Неверные типы, слишком длинные значения и метаданные цитаты у общей записи
отклоняются до восстановления. Отсутствующий адресат допускается: фрагмент
остаётся самостоятельным. Связывание, сохранение и отвязка выполняются в Room
транзакциях, ограничены текущей книгой и не меняют словарные переводы/ИИ-кеш.

## Проверки и ограничения

Новые тесты `BookKnowledgeTest` и `BookKnowledgeFlowTest` проверяют группировку,
поиск, старые заметки, потерянного адресата, отвязку, изоляцию книг, backup и
перенумерацию, экспорт источников, сохранение ручной заметки, отсутствие дублей,
другой экземпляр ViewModel, добавление Википедии и настоящий Compose-интерфейс
списка/деталей/экспорта/перехода. `MigrationTest` проверяет обновление с 16 и
прежних схем. Результаты запуска и сборки дополняются после завершения проверок.

Раздел содержит сохранённые фрагменты, а не автоматический индекс всех упоминаний
в произведении. Короткий контекст используется как выдержка; для более длинной
цитаты нужно выделить её целиком. Исходный текст выбранного диапазона также хранится.
Это не чтение полных статей Википедии внутри приложения и не новостная лента.
Переимпорт другой редакции EPUB не переносит адреса между разными книгами.
Физический Android-телефон в этой среде не подключён; реальные проверки на нём
и запросы DeepSeek не выполнялись.
